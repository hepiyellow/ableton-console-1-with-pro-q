# Console1Control

A minimalist Ableton Live remote script that does nothing.

## Description

This is a stripped-down Ableton Live MIDI remote script that initializes and logs a message when loaded, but otherwise performs no functions. It can be used as a starting point for developing custom Ableton Live MIDI remote scripts.

## Installation

1. Place the entire folder in your Ableton Live Remote Scripts directory:

   - macOS: `~/Music/Ableton/User Library/Remote Scripts/`
   - Windows: `\Users\[username]\Documents\Ableton\User Library\Remote Scripts\`

2. Start Ableton Live
3. Go to Preferences > Link MIDI
4. Select "Console1Control" from the Control Surface dropdown menu

## Files

- `Console1Controller.py` - Main controller class
- `__init__.py` - Script initialization
